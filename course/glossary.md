# 概念词典

规则：尽量使用自己的语言，每个概念至少包含“是什么”和“解决什么问题”。

| 概念 | 我的解释 | 例子或类比 | 是否能独立解释 |
|---|---|---|---|
| 文件 | 具体的信息存放 | 快递 | 否 |
| 目录 | 文件的集合 | 包裹 | 否 |
| 路径 | 指明文件存放地址的指示牌 | 地址 | 否 |
| 终端 | 命令写入和执行的地方 | 快递员 | 否 |
| Git | 一个具体写入读取提交文件的工具 | 快递车 | 否 |
| GitHub | 网络上的一个仓库 | 快递公司 | 否 |
| 仓库 | 上传文件的集合 | 待填单 | 否 |
