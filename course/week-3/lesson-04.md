# 第 14 课：评测驱动的摘要改进

## 借鉴并融合

借鉴 [autoresearch](https://github.com/karpathy/autoresearch) 的“提出改动 → 运行实验 → 记录指标 → 保留更优版本”循环，但把训练指标替换成周报质量指标。

## 本课产物

建立一个至少包含 10 篇论文的固定评测集和一张实验记录表。

## 质量维度

每项使用明确的 0～2 分规则：

- 忠实性：结论是否由原摘要支持；
- 覆盖度：贡献、方法、结果是否齐全；
- 引用正确性：来源是否存在且匹配；
- 可读性：是否清楚、简洁、术语适量；
- 格式有效性：结构化字段和 Markdown 是否通过检查；
- 成本与延迟：是否在设定预算内。

## 实验规则

一次只改变一个变量，例如提示词、模型或检索条数。记录基线、改动、预期、实际分数、成本和结论。失败实验也保留记录。

## 第 3 周验收

- [ ] Mock 端到端测试通过。
- [ ] 真实模型对固定评测集运行一次。
- [ ] 至少比较两个提示词版本，能用指标解释选择。
- [ ] 报告中的引用全部通过程序校验。
- [ ] 展示一次失败恢复和一次预算停止。

通过后，你完成的不是“调用一次大模型”，而是一个可验证的论文研究 Agent。
