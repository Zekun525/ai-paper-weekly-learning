# Git/GitHub 与 AI 工程实战课

这不是一套“复制命令即可完成”的教程，而是一套以真实项目为主线的训练。

最终作品：**语义通信最新论文自动周报**。

## 学习循环

每一课都按以下顺序进行：

1. 理解概念和它要解决的问题。
2. 在运行命令前预测结果。
3. 跟随最小示范完成第一次操作。
4. 独立完成闯关任务。
5. 用自己的话解释原理。

不要追求背下所有命令。真正重要的是：知道当前状态、知道想改变什么、知道如何验证结果。

## 四周路线

- 第 1 周：终端、Git、GitHub、分支、Pull Request 和冲突。
- 第 2 周：Python 环境、HTTP/API、论文采集和自动测试。
- 第 3 周：大模型、RAG、Mock、摘要生成和静态网页。
- 第 4 周：GitHub Actions、Secrets、GitHub Pages 和求职表达。
