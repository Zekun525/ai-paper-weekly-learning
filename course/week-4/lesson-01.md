# 第 15 课：GitHub Actions 持续集成

## 本课产物

每次 push 和 Pull Request 自动执行格式检查、静态检查和测试。

## 实践任务

1. 创建最小 CI 工作流。
2. 固定 Python 大版本，并使用依赖缓存。
3. 默认运行不联网、不调用真实模型的快速测试。
4. 给工作流设置最小权限和超时。
5. 故意制造一个测试失败，读懂日志后修复。

成熟开源项目的 CI 价值不在徽章，而在“每个贡献者都按相同方式验证”。工作流中的命令必须也能在本地运行。

## 验收

- [ ] PR 页面显示自动检查。
- [ ] 失败日志能定位到具体测试或规则。
- [ ] CI 不依赖任何真实 API Key。
- [ ] 工作流具有 `timeout-minutes` 和明确权限。
