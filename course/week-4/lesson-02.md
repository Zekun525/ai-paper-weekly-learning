# 第 16 课：定时任务、Secrets 与安全发布

## 本课产物

建立一个可手动触发、可定时运行、失败不会覆盖成功报告的周报工作流。

## 实践任务

1. 先支持 `workflow_dispatch`，验证无误后再加入每周定时。
2. 将模型密钥放入 GitHub Actions Secrets，不写入代码、日志和产物。
3. 用并发锁避免同一期任务重复运行。
4. 设置最大论文数、模型调用次数、重试次数、总超时和预算。
5. 先生成临时报告，通过引用和格式检查后再替换正式报告。
6. 失败时保留诊断信息，但对日志做敏感信息脱敏。

## 验收

- [ ] 手动触发成功后才开启定时。
- [ ] 日志和仓库历史中搜不到真实密钥。
- [ ] 同一期重复运行不会产生重复内容。
- [ ] 任一关键校验失败时，旧报告仍可访问。
- [ ] 能安全解释如何轮换或撤销密钥。
