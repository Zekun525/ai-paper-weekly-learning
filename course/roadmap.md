# 完整学习路线与产物地图

这条路线把高星 AI Agent 项目的优秀设计，压缩成适合初学者逐步完成的一个真实项目。所有课程围绕同一个最终作品：**语义通信最新论文自动周报**。

## 融合关系

| 参考项目 | 吸收的设计 | 融入本课程的位置 | 不照搬的部分 |
|---|---|---|---|
| awesome-llm-apps | 小而完整的应用、先跑通纵向链路 | 第 7 课先做离线版完整周报 | 不复制示例合集或同时学习多个框架 |
| LangChain | 组件接口、模型适配、检索边界 | 第 11～12 课摘要器协议与 RAG | 初期不引入整套框架和复杂抽象 |
| DeerFlow | 计划、研究、综合、长流程状态 | 第 13 课可恢复研究状态机 | 不照搬多 Agent 和完整基础设施 |
| browser-use | 受限工具、超时、重试、操作范围 | 第 8、13、16 课的外部工具可靠性 | arXiv 有官方 API，不用浏览器抓取替代 |
| autoresearch | 固定基线、单变量实验、指标记录 | 第 14 课摘要评测循环 | 不进行高成本模型训练 |
| 高质量 GitHub 项目实践 | 小 PR、CI、文档、可复现环境 | 第 1 周与第 15～18 课 | 不追求复杂流程或徽章数量 |

## 18 课产物

| 周次 | 课程 | 交付物 |
|---|---|---|
| 第 1 周 | 1～6 | Git 仓库、清晰提交、GitHub 远程、PR、冲突解决记录 |
| 第 2 周 | 7～10 | 离线周报、arXiv 采集器、规范化快照、自动测试 |
| 第 3 周 | 11～14 | 可替换摘要器、RAG 引用、Agent 状态机、质量评测集 |
| 第 4 周 | 15～18 | CI、定时安全运行、GitHub Pages、可演示的 v1.0 项目 |

## 依赖关系

```text
Git/GitHub 基础
    ↓
离线完整周报 → 真实 arXiv 数据 → 稳定数据快照 → 测试保护
    ↓
可替换模型 → 检索与引用 → 可恢复 Agent → 评测改进
    ↓
CI → 定时安全运行 → Pages 发布 → v1.0 验收
```

不要跳过箭头前面的产物。后面的每一层都应能被前一层的测试与数据快照支撑。

## 学习节奏

推荐每课 60～120 分钟。如果一课未通过验收，不勾选进度，也不继续增加新依赖。卡住时先写错误手册，再向老师提交预测、完整错误、已做验证和当前猜测。
