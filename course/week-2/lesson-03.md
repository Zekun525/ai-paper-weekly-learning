# 第 9 课：清洗、去重、排序与可复现快照

## 本课产物

把 API 原始结果变成稳定、可比较、可重复运行的论文集合。

## 实践任务

1. 规范标题和摘要中的多余空白。
2. 统一日期与时区。
3. 使用 arXiv ID 作为主要去重键，不用标题模糊猜测替代稳定标识。
4. 明确版本更新如何处理：覆盖、保留或标注。
5. 使用固定排序规则，例如发布日期降序后按 ID 排序。
6. 将规范化结果保存成 JSON 快照，记录查询条件和生成时间。

## 为什么这是 Agent 的基础

Agent 不能只“看起来聪明”。若输入顺序、重复项和状态不可控，同样的任务会产生难以解释的不同结果。稳定数据层让后续模型输出可以测试和追踪。

## 验收

- [ ] 同一输入运行两次，规范化论文顺序一致。
- [ ] 重复 ID 只保留符合规则的一项。
- [ ] 空标题、无摘要或非法日期有明确策略。
- [ ] JSON 快照可以离线重建 Markdown 周报。
