# 第 6 课：冲突实验与第 1 周验收

## 本课产物

在可控文件中制造一次冲突，读懂冲突标记，手工合并并通过周验收。

## 冲突实验

新建两个分支，让它们修改 `course/conflict-lab.md` 的同一行。先合并其中一个，再合并另一个。出现冲突后查看：

```powershell
git status
git diff
```

冲突标记含义：

```text
<<<<<<< 当前分支
当前版本
=======
待合并版本
>>>>>>> 另一分支
```

人工决定最终内容，删除所有标记，再暂存、提交。不要把“选择当前”或“选择传入”当成无需思考的答案。

## 第 1 周验收

独立完成以下任务：

1. 从干净的 `main` 创建分支。
2. 做一项小改动并通过 diff 检查。
3. 提交、推送并创建 PR。
4. 解释本地分支、远程分支和 PR 的关系。
5. 展示一次冲突的原因、解决方案和最终 diff。

通过标准：操作成功只是基础；还要能根据 `status`、`diff`、`log` 解释当前状态。通过后才能在进度表勾选第 1 周，并进入 Python 项目开发。
