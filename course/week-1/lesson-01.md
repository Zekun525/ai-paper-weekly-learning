# 第 1 课：终端、路径与 Git 仓库

## 本课目标

完成本课后，你应该能够：

- 解释终端、当前目录和路径是什么。
- 解释 Git 与 GitHub 的区别。
- 把普通目录初始化为 Git 仓库。
- 使用 `git status` 判断仓库当前状态。

## 一、基本概念

### 文件、目录与路径

- **文件**是保存内容的单位，例如 Python 程序、图片和配置文件。
- **目录**用于组织文件，也常被称为文件夹。
- **路径**是文件或目录在计算机中的地址。
- `D:\ailearning` 是绝对路径：从盘符开始，位置明确。
- `course\README.md` 是相对路径：它的位置依赖当前目录。

可以把文件系统想象成一栋楼：目录是房间，文件是房间里的物品，路径是从入口走到物品的路线。

### 终端与命令

终端是用文字向操作系统下达命令的界面。PowerShell 是你当前使用的命令解释器，它读取命令、执行程序并显示结果。

注意：终端不是 Git。Git 只是能够从终端调用的众多程序之一。

### Git 与 GitHub

- **Git** 是安装在本机上的版本控制工具，用来保存和比较项目历史；断网也能工作。
- **GitHub** 是互联网上的代码托管和协作平台，可以保存远程 Git 仓库、进行代码审查和运行自动化任务。

类比：Git 像本地游戏存档系统，GitHub 像云存档加协作平台。

### Git 仓库

普通目录只保存当前文件。执行 `git init` 后，Git 会创建隐藏的 `.git` 目录，用它保存版本历史和配置。`.git` 才是仓库的核心，不要手工修改其中内容。

`git init` 不会把代码上传到 GitHub，也不会自动保存文件版本。

## 三、实践任务

确认 VS Code 终端位于 `D:\ailearning`，逐条执行：

```powershell
Get-Location
Get-ChildItem
git --version
git status
git init
git status
Get-ChildItem -Force
```

不要把所有命令一次粘贴执行。每执行一条，先看输出，再继续。

## 四、观察重点

- `git init` 前后的 `git status` 有何不同？
- `Get-ChildItem` 与 `Get-ChildItem -Force` 的结果有何不同？
- 初始化后出现了哪个隐藏目录？
- 课程文件目前是 tracked 还是 untracked？
